## Offline -- The device outbox and the PWA shell

### Overview

The offline block is what keeps a phone useful when the connection drops: the installable shell (manifest + service worker), the `/offline` page the worker serves when a navigation cannot reach the network, and the **outbox** — an IndexedDB queue of work done offline that drains through `POST /api/offline/sync` with a verdict per item.

Policy (2026-08-30): nothing from the server is copied to a device. No lessons, no media, no cached dashboards. The outbox holds only what the user _produced_.

### Pieces

| Piece          | Path                                                      | Role                                                                                                                                                                                                        |

### Rules

- **Never precache a redirect.** `/` and `/offline` are 307s to the locale prefix; a stored redirected response is refused for navigations. Precache locale-explicit URLs only.
- **Never cache `/api/` bodies**, and never serve a saved page from any namespace but the current session key's. Shared school devices.
- **Bump the cache name** on every worker change.

## Explorable offline (2026-09-13)

Policy change: the pages a signed-in user opens ARE kept on the device now — the HTML of a full load and the RSC payload of a client-side navigation — so the dashboard can be walked without a connection. What makes that safe on a shared device is the namespace: `src/proxy.ts` puts `x-session-key` (a truncated SHA-256 of the user id and `AUTH_SECRET`) on every response, the worker names its page caches by it, and a response carrying a different key or none deletes every other namespace before anything is served. Signing out, or someone else signing in, empties the previous person's pages; the key can only change online, so an offline replay is always the last signed-in person's own screens.

- **Network first, saved copy second.** A page with no saved copy waits for the network. One with a saved copy is shown from it when the network fails or has not answered in 4 s, and the fetch keeps running to refresh the copy. The worker tells the page (`sw-stale`) so the strip says "slow connection — saved copy" with a Retry; going offline says "opened pages still work".
- **A failed RSC request answers 503, never throws.** The router treats a non-RSC answer as "do a full navigation", which lands on the saved HTML or the offline page. `experimental.useOffline` is on as well: Server Actions that fail for lack of network wait and retry when it returns.
- **Warm-up.** `warmup.tsx` (installed app, 4G, data saver off, idle) sends the role's sidebar URLs; the worker fetches them 1.5 s apart, saves each with the build chunks its HTML references, once a day per key.
- **Why it was slow before (fixed the same day).** The proxy wrote the `NEXT_LOCALE` cookie on every response; Next merges proxy-set cookies into the request store's mutable cookies, and a Server Action whose store shows a modified cookie is answered with a full re-render of the page (`x-action-revalidated`) — 1.1 MB, twice on every dashboard open — and a purge of the router cache that re-fired every prefetch. The cookie is written only when it changes now. Static chunks are also cached at Cloudflare's edge by `cf/worker.js` instead of round-tripping to the one container per file.
- Verify with the kun audit: `node ~/.claude/skills/pwa/scripts/pwa-audit.mjs <url> --sw /service-worker.js`.

## Install card (2026-09-13)

`install-card.tsx` is an iOS sheet like the Activity View (Figma `iuYSGaRV8xkcEGnyIltPRg` 34:3042): the project `Drawer`
— rounded top over the dimmed page, grabber, round close button, swipe or X to dismiss. Inside:
the orange eyebrow over the app name, ONE picture (a mock of the share list with "Add to Home
Screen" lit up in the dashboard green), and a green **Continue**. Continue does only the native
thing: the captured `beforeinstallprompt` on Android, otherwise `navigator.share()` from the tap
(on iPhone Add to Home Screen is one of the sheet's actions). No footnote, no guide, no Not now. Platform detection is
a `useSyncExternalStore` snapshot (no state set inside effects); hidden when installed, on
desktop, or for 14 days after dismissal. Strings live under `lumos.offline.install*` in both
dictionaries. The app icon is a Claude-orange box (`#e8704e`) with the white feather at 56 % of
the box, generated by `scripts/gen-pwa-icons.mjs` from `public/feather.png` (one artwork for
iOS, Android maskable and the tab). Verify on a phone or with a spoofed iPhone user agent in
chrome-devtools.
