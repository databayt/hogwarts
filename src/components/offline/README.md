## Offline -- The device outbox and the PWA shell

### Overview

The offline block is what keeps a phone useful when the connection drops: the installable shell (manifest + service worker), the `/offline` page the worker serves when a navigation cannot reach the network, and the **outbox** — an IndexedDB queue of work done offline that drains through `POST /api/offline/sync` with a verdict per item.

Policy (2026-08-30): nothing from the server is copied to a device. No lessons, no media, no cached dashboards. The outbox holds only what the user *produced*.

### Pieces

| Piece | Path | Role |
| --- | --- | --- |
| Manifest | `src/app/manifest.ts` | Per-tenant: resolves the school from the Host (the proxy never sees dotted paths), answers with its name, language, direction and brand colour |
| Service worker | `public/service-worker.js` (v3) | Precaches `/ar/offline` + `/en/offline` only; static assets cache-first (capped); navigations and `/api/` network-only; push + click handlers |
| Registration | `src/components/providers/service-worker-provider.tsx` | Production only (`NEXT_PUBLIC_SW_DEV=1` for a local `next start`) |
| Offline page | `src/app/[lang]/offline/page.tsx` → `content.tsx` | Public route, no server data; shows the outbox |
| Outbox | `src/lib/offline/{db,outbox,hooks}.ts` | Enqueue, coalesce, backoff, drain; `useOnlineStatus`, `useOutbox` |
| Sync route | `src/app/api/offline/sync/route.ts` | Idempotent per item: `applied` / `duplicate` / `rejected` |
| Banner | `sync-banner.tsx` | Mounted in the school-dashboard layout; visible only while items wait |
| Icons | `public/icon-{72,96,192,512}.png`, `apple-touch-icon.png` | Generated by `scripts/gen-pwa-icons.mjs` from the 512 master |

### Outbox kinds

| Kind | Producer | Server core | Natural key |
| --- | --- | --- | --- |
| `progress` | Lumos player | `applyLessonProgress` | newer wins |
| `complete` | Lumos player | `completeLessonCore` | lesson |
| `quiz` | Lumos quiz | `submitLessonQuizCore` | attempt id |
| `assignment` | Assignments | `submitAssignmentCore` | newer wins |
| `attendance` | Quick attendance (`attendance/quick/content.tsx`) | `submitQuickAttendanceCore` | section + day; coalesced on the device, `stale` when the server already holds a newer mark |

### Rules

- **Never precache a redirect.** `/` and `/offline` are 307s to the locale prefix; a stored redirected response is refused for navigations. Precache locale-explicit URLs only.
- **Never cache authenticated HTML or API bodies.** Shared school devices.
- **Bump the cache name** on every worker change.
- Verify with the kun audit: `node ~/.claude/skills/pwa/scripts/pwa-audit.mjs <url> --sw /service-worker.js`.

## Install card (2026-09-13)

`install-card.tsx` is an iOS sheet like the Activity View (Figma `iuYSGaRV8xkcEGnyIltPRg` 34:3042): the project `Drawer`
— rounded top over the dimmed page, grabber, round close button, swipe or X to dismiss. Inside:
the orange eyebrow over the app name, ONE picture (a mock of the share list with "Add to Home
Screen" lit up in the dashboard green), and a green **Continue**. Continue does only the native
thing: the captured `beforeinstallprompt` on Android, otherwise `navigator.share()` from the tap
(on iPhone Add to Home Screen is one of the sheet's actions). No footnote, no guide, no Not now. Platform detection is
a `useSyncExternalStore` snapshot (no state set inside effects); hidden when installed, on
desktop, or for 14 days after dismissal. Strings live under `lumos.offline.install*` in both
dictionaries. The app icon is a Claude-orange box (`#e8704e`) with the white feather at 56 % of
the box, generated by `scripts/gen-pwa-icons.mjs` from `public/feather.png` (one artwork for
iOS, Android maskable and the tab). Verify on a phone or with a spoofed iPhone user agent in
chrome-devtools.
