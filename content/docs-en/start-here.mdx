## Why it pays

A broken login found on a sales call costs us a school. Found in a two-minute check, it costs nothing. And work only counts where it is recorded — GitHub, the CRM, the group — so your access to all three must work.

## Set up your machine with Kun

One line in a terminal. It takes about 20 minutes, installs only what is missing, and can be run again any time.

```bash
curl -fsSL https://kun.databayt.org/install | bash
```

On Windows (PowerShell):

```powershell
powershell -ExecutionPolicy Bypass -Command "iwr https://kun.databayt.org/install.ps1 | iex"
```

You get Claude Code (type `c` to start it), every databayt repo cloned, and the same config as the rest of the team. The full guide: [Kun onboarding](https://kun.databayt.org/en/docs/onboarding).

## Health check

| Check                         | How                                                                                       | Pass                          |
| ----------------------------- | ----------------------------------------------------------------------------------------- | ----------------------------- |
| You are in the databayt org   | `gh api user/memberships/orgs/databayt --jq .state`, or find your name at [github.com/orgs/databayt/people](https://github.com/orgs/databayt/people) | `active` |
| GitHub knows this machine     | `gh auth status` then `ssh -T git@github.com`                                             | "Logged in", "successfully authenticated" |
| Kun is healthy                | `bash ~/.claude/scripts/health.sh`                                                        | `✅ healthy`                  |
| Your email works              | Sign in to name@databayt.org                                                              | The inbox opens               |
| The CRM opens                 | [hogwarts.databayt.org](https://hogwarts.databayt.org) with that email                    | Your deals show               |
| The demo runs                 | [demo.balqalam.com](https://demo.balqalam.com) on your phone → "Try the platform"         | A school dashboard opens      |
| You are in the group          | WhatsApp «المدرسة 2.0»                                                                    | You see this week's plan      |

A red row on Kun? `bash ~/kun/.claude/scripts/onboarding-mac.sh --doctor` prints the fix for each one, and changes nothing.

## When this happens

- **A check is red and its hint doesn't fix it** → say it in the group, with the row and what you saw.
- **You get a new laptop** → run the Kun line, then the health check.
- **You lose access to the org, your email or the CRM** → tell Abdout the same day.
- **A link here is dead** → say which one in the group.

## What you do

Run the health check now, and again on any new machine.
