This page is **the publishing gate**. No number, result or feature outside these tables is used until its status is updated. If documents conflict, publishing stops and the conflict goes into the conflicts table below — instead of picking the more attractive claim.

## Forbidden claims

| Don't say                              | Why                      | Say instead                                       |
| -------------------------------------- | ------------------------ | ------------------------------------------------- |
| We saved 80% of the time               | Not measured             | Describe the task that got shorter                |
| We cut costs 60%                       | Not measured             | Explain the price and what it includes            |
| We raised admissions 25%               | Not measured             | Explain the digital admissions flow               |
| 99.9% uptime                           | No published SLA         | No number                                         |
| We save 30–40 hours a month            | Not measured             | "Ends retyping data"                              |
| Pays for itself in two or three months | Not proven               | Explain price and task, no invented ROI           |
| Our paying customers                   | Current revenue is zero  | "Our pilot school"                                |
| 12,000 students or 8 schools           | Not true                 | "One live school and 9 open pilot seats"          |
| Supports the Hijri calendar            | Doesn't exist            | Don't mention it                                  |
| Works offline                          | Not shipped              | "Built for slow connections"                      |
| Download our app                       | No store app             | "Open it in the browser and install it to your home screen" |
| Advanced analytics                     | Dashboard incomplete     | "Attendance, grades and fees reports"             |
| Six payment gateways                   | Not true                 | Name only live methods, after verification        |

## Correction policy

If we publish something inaccurate:

1. We don't delete silently unless the harm is ongoing.
2. We correct the copy visibly.
3. We log the error in the conflicts table above.
4. We update the template or the [agent](/docs/marketing/growth-editor) so it doesn't recur.
