## Steps

1. When a class starts and **5 minutes** pass without its teacher, you get an alert as class supervisor, and so does the administration. Tap the notification.
2. Choose one:
   - **Enter as the class teacher** to teach the class yourself or keep the students in the room.
   - **Book a make-up class** for a later time. See [Make-up classes](/docs/support/makeup-class).
3. To see who is ready, open **Class readiness** from the app menu, or **School ← Analysis** on the web.
4. The report shows each class: who uses the app, who hasn't attended a class since the start of the week, who has never signed in, who entered a wrong password many times, and who isn't getting notifications.
5. Every morning you get a **daily summary** of the day's classes and everyone's readiness, so call anyone flagged before their class.

## Good to know

- Each class has one or more supervisors, and a supervisor can enter and cover any class in theirs.
- To get absence alerts you need the **latest app version** and **notifications on**.
- Anyone flagged "Android browser: needs to install the app" must install it. See [Installing the school app](/docs/support/install-app).
- For someone who keeps entering a wrong password, ask the school administration to reset it.

## Troubleshooting

- **I don't get the teacher-absent alert**: update the app and turn notifications on (**Allow**). See [Notifications](/docs/support/notifications).
- **I can't find "Enter as the class teacher"**: you aren't registered as supervisor of that class; ask the administration to register you.
- **Students are in class and there is no teacher**: the supervisor enters and covers it, or books a make-up class.
- **I don't see the readiness report**: it is shown to supervisors and the administration only.
