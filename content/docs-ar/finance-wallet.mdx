---
title: المحفظة
description: محافظ رصيد مخزَّن بلا نقد للطلاب والكادر — الشحن والأرصدة والإنفاق. إدارة المحافظ والشحن تعملان، لكن الشحن لا يرحّل إلى الدفتر، ولا يوجد مسار استرداد ظاهر، ودفع PIN/QR غير مبني.
---

تمنح المحفظة كل مستخدم رصيداً مخزَّناً للمعاملات المدرسية بلا نقد — يشحنه، ويحتفظ برصيد، و(مستقبلاً) يدفع منه الرسوم. تعيش الواجهة في `content.tsx`؛ ولا توجد بعد مكوّنات مخصصة للجدول/الأعمدة/النموذج.

## التدفق

```
Create wallet  →  top up (payment method)  →  hold balance  →  spend (e.g. pay fees)
```

## إجراءات الخادم

| الإجراء        | الغرض                           |
| -------------- | ------------------------------- |
| `createWallet` | إنشاء محفظة لمستخدم             |
| `getWallets`   | عرض المحافظ (مقيّدة بالمستأجر)  |
| `topupWallet`  | إضافة أموال إلى محفظة           |
| `refundWallet` | عكس الأموال (بلا مسار ظاهر بعد) |

## دفتر الأستاذ / المحاسبة

**لا ترحّل إلى الدفتر.** توجد `postWalletTopup` في المحرك لكن بلا أي مستدعٍ، فلا تنشئ الشحنات قيود `DR Cash / CR Unearned Revenue` التي يصفها README. وعكس شحنة زائدة يتطلب قيد يومية يدوياً في [الحسابات](/docs/finance-accounts).
