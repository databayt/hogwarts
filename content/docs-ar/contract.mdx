**صفحة واحدة، بكلام بسيط، وهي نفسها لكل مدرسة.**

## ماذا يقول العقد

| البند          | بكلام بسيط                                                                |
| -------------- | ------------------------------------------------------------------------- |
| الخدمة         | منصة بالقلم كاملة على عنوان المدرسة الخاص، مع الدعم والتحديثات            |
| الشهر المجاني  | الشهر الأول بلا تكلفة                                                      |
| السعر          | 6.40 دولار لكل طالب في السنة، بعدد الطلاب يوم كل دفعة                     |
| الدفع          | 50% عند نهاية الشهر المجاني، ثم 12.5% كل ثلاثة أشهر                       |
| طريقة الدفع    | بالجنيه السوداني بسعر البنك يوم الدفع، عبر بنكك، إلى الحساب المكتوب في الفاتورة |
| البيانات       | البيانات ملك المدرسة وتصدّرها متى شاءت، ونحن نحفظ سريّتها                 |
| المدة          | سنة واحدة، تتجدّد ما لم يعتذر أحد الطرفين قبل نهايتها بـ30 يومًا           |
| تأخّر الدفع    | بعد 30 يومًا من التأخّر وإشعار مكتوب، يحق لنا إيقاف الدخول مؤقتًا، وتبقى البيانات محفوظة |

## كيف تملؤه

1. اسم المدرسة، ومن يوقّع، وعدد الطلاب.
2. تاريخ البدء، ويوم انتهاء الشهر المجاني.
3. المبالغ — خذها من صفحة الأسعار.
4. عثمان يوقّع عن داتابايت.

## ما عليك

- لا تغيّر أي بند بنفسك. أرسل أي تعديل تطلبه المدرسة إلى عثمان.
- ضع النسخة الموقّعة في نظام إدارة العملاء في اليوم نفسه.
