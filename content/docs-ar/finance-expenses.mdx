---
title: المصروفات
description: تقديم المصروفات، وسير الاعتماد، والفئات، والتكامل مع الميزانية. الإدارة والاعتماد وخصم الميزانية تعمل؛ أما مدفوعات المصروفات فلا ترحّل إلى الدفتر، وبريد سلسلة الاعتماد غير موصول، وملف محتوى قديم بانتظار الحذف.
---

تتيح وحدة المصروفات للكادر تقديم التكاليف، وتمرّرها عبر الاعتماد، وتخصم المبالغ المعتمدة من تخصيصات [الميزانية](/docs/finance-budget)، وتعالج السداد. وتُدار الفئات إلى جانبها.

## التدفق

```
Submit expense (DRAFT)  →  approve / reject  →  on approval, deduct from budget allocation
  →  process payment (reimbursement)
```

## الحالة

| الميزة                                      | الحالة                                         |
| ------------------------------------------- | ---------------------------------------------- |
| إدارة المصروفات (مقيّدة بـ `schoolId`)      | Production                                     |
| إدارة الفئات                                | Production                                     |
| آلة حالات الاعتماد                          | Production                                     |
| خصم الميزانية عند الاعتماد                  | Production                                     |
| إشعار بالبريد عند تغيّر الاعتماد            | مخطط                                           |
| قواعد توجيه الاعتماد (بالمبلغ/الفئة)        | مخطط                                           |
| استيراد جماعي من CSV                        | مخطط                                           |
| مسح الإيصالات بـ OCR / ربط المصروف بالإيصال | مخطط (راجع [الإيصالات](/docs/finance-receipt)) |

## المسارات

| المسار                                | الصفحة             | الحالة |

## إجراءات الخادم

| الإجراء                           | الغرض                               |
| --------------------------------- | ----------------------------------- |
| `createExpense` / `updateExpense` | إنشاء المصروف / تعديله              |
| `approveExpense`                  | اعتماد/رفض؛ يخصم من تخصيص الميزانية |
| `createExpenseCategory`           | إضافة فئة مصروف                     |
| `getExpenses`                     | عرض المصروفات (مقيّدة بالمستأجر)    |

## دفتر الأستاذ / المحاسبة

**لا ترحّل إلى الدفتر.** توجد `postExpensePayment` في المحرك لكن بلا أي مستدعٍ، فاعتماد المصروف أو دفعه لا ينشئ قيود يومية (ادعاء README حول `lib/accounting/` طموح لا واقع). غير أن الاعتماد يُنقص تخصيص الميزانية المرتبط.

## المخطط

`prisma/models/finance-budgets.prisma`: `Expense` و`ExpenseCategory` — مقيّدان بـ `schoolId`. **يخزّن `ExpenseCategory` أسماء الفئات الظاهرة للمستخدم دون حقل `lang`**، فتُعرض الفئات بلغتها المخزّنة فقط.
