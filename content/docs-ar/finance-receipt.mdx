الإيصالات أداة **التقاط إيصالات المصروفات**: ترفع صورة أو PDF لإيصال فيستخرج مسار ذكاء اصطناعي التاجر والتاريخ والمبلغ والبنود لتتبّع المصروفات. وهي ليست مولّد إيصال الدفع — فالإيصال الصادر عن دفع الرسوم يُنتَج بواسطة [`fees/receipt-pdf.tsx`](/docs/fees) (مستند `@react-pdf/renderer` يعمل).

## التدفق

```
Upload image / PDF  →  AI extraction (pending → processing → processed | error)
  →  retry on failure  →  (manual) attach to an expense record
```

يمر تقييد الخطة عبر Schematic.io (مسار `receipt/manage-plan`)؛ وتأتي الاستحقاقات من `receipt/schematic/`.
