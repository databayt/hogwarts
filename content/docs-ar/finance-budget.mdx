---

تحدّد الميزانية أغلفة الإنفاق، وتوزّعها على الفئات، وتتتبّع الانحراف بين المصروف والمخصَّص. تخصم [المصروفات](/docs/finance-expenses) من التخصيصات عند الاعتماد؛ ويغذّي الانحراف الناتج [التقارير](/docs/finance-reports).

## التدفق

```
Create budget  →  allocate to categories  →  track spent vs allocated (variance)
  →  (planned) alert when a threshold is crossed
```

## الحالة

| الميزة                                    | الحالة                                                         |
| ----------------------------------------- | -------------------------------------------------------------- |
| إدارة الفئات (مقيّدة بـ `schoolId`)       | Production                                                     |
| التخصيص + تتبّع المصروف                   | Production                                                     |
| حساب الانحراف (المخصَّص مقابل المصروف)    | Production                                                     |
| مصنع التحقق `createBudgetSchema(v)`       | مُصدَّر، لكن المستهلكين ما زالوا يستوردون المخطط الثابت القديم |
| إشعارات تنبيه الانحراف                    | مخطط (حد ← إرسال، غير موصول)                                   |
| صفحة تقرير الميزانية مقابل الفعلي         | مخطط (البيانات موجودة، بلا واجهة)                              |
| سير الاعتماد                              | مخطط                                                           |
| ميزانيات متعددة الفترات (ربع سنوية/سنوية) | مخطط                                                           |

| `createBudget` / `updateBudget` | إنشاء الميزانية / تعديلها  |

| `getBudgets`                    | عرض الميزانيات + التخصيصات |

## دفتر الأستاذ / المحاسبة

ليست محرّكاً لحركة المال في الدفتر. تتتبّع الميزانية الإنفاق المخطط مقابل الفعلي؛ وجانب "الفعلي" يُخصم باعتماد المصروفات، لا بترحيلات اليومية.

## المخطط

`prisma/models/finance-budgets.prisma`: `Budget` و`BudgetAllocation` — مقيّدان بـ `schoolId`. لا يوجد حقل `lang` لأسماء الميزانيات والفئات.

## العناصر المؤقتة

- `validation.ts:29` — رسالة نطاق التاريخ مكتوبة يدوياً؛ ولم يتبنَّ `form.tsx` / `actions.ts` بعد المصنع المُصدَّر `createBudgetSchema(v)` (ما زال `budgetSchema` الثابت القديم مستورداً).
