يحدّد الراتب الأجر الأساسي لكل معلم، والبدلات الخاضعة وغير الخاضعة للضريبة، والخصومات. وهذه الهياكل النشطة هي ما يقرؤه [كشف الرواتب](/docs/finance-payroll) عند توليد القسائم. إنشاء هيكل جديد يعطّل السابق تلقائياً — ولا يُحتفظ بأي تاريخ.

## المسار

```
1. Create structure (deactivates the teacher's prior active one)  — createSalaryStructure
2. Attach allowances / deductions                                 — addAllowance / addDeduction
3. (optional) Calculate: gross, taxable income, tax (flat 15%), net — calculateSalary
4. (optional) Apply increment (fixed or %) → new active structure  — applySalaryIncrement
```

## الحالة

| الميزة                                    | الحالة                                           |
| ----------------------------------------- | ------------------------------------------------ |
| إدارة هياكل الرواتب + القائمة (DataTable) | Production                                       |

| حاسبة الراتب                              | جاهز (الضريبة نسبة ثابتة 15%)                    |
| العلاوة (مبلغ ثابت / نسبة مئوية)          | جاهز                                             |
| تصدير الهياكل إلى CSV                     | Production (من جهة العميل، مقيّد بـ `canExport`) |
| ترجمة الأسماء عند الطلب في القائمة        | Production (`getText` وقت القراءة)               |
| نموذج إنشاء هيكل في الواجهة               | مؤقت — عنصر نائب "قريباً"                        |
| تاريخ الراتب                              | مخطط (يُستبدل عند التحديث)                       |
| بدلات بالمعادلة (مثل 20% من الأساسي)      | مخطط                                             |
| ضريبة خاصة بكل بلد                        | مخطط                                             |
| ترحيل اليومية                             | مخطط (لا شيء اليوم)                              |

## إجراءات الخادم

كلها تستخدم `auth()` + `getTenantContext()`. وتُفرض الصلاحيات (RBAC) في `content.tsx`. ولا يغلّف أيٌّ منها الكتابات بـ `db.$transaction`.

| الإجراء                                                | الغرض                                                    |
| ------------------------------------------------------ | -------------------------------------------------------- |
| `getSalaryStructures` / `getSalaryStructure`           | عرض / قراءة هيكل واحد (+ البدلات والخصومات وآخر القسائم) |
| `createSalaryStructure`                                | تعطيل النشط السابق، وإنشاء هيكل نشط جديد                 |
| `updateSalaryStructure` / `deactivateSalaryStructure`  | تحديث / إنهاء هيكل                                       |
| `addAllowance` / `updateAllowance` / `deleteAllowance` | إدارة البدلات                                            |
| `addDeduction` / `updateDeduction` / `deleteDeduction` | إدارة الخصومات                                           |
| `calculateSalary`                                      | حساب الإجمالي / الخاضع للضريبة / الضريبة (15%) / الصافي  |
| `applySalaryIncrement`                                 | تعطيل الهيكل وإنشاء خليفة بعد العلاوة                    |
| `getSalarySummary`                                     | الأعداد + متوسط الراتب الأساسي                           |

## المفاهيم

| المفهوم         | القيم                                |
| --------------- | ------------------------------------ |
| `PayFrequency`  | MONTHLY, BI_WEEKLY, WEEKLY, DAILY    |
| `DeductionType` | TAX, INSURANCE, LOAN, PENSION, OTHER |

| أعلام البدلات   | `isTaxable`, `isRecurring`           |

## دفتر الأستاذ / المحاسبة

**لا يرحّل إلى الدفتر.** ادعاء README حول "قيود يومية عبر `lib/accounting/`" طموح لا واقع — فهذه الوحدة لا تستورد المحرك أبداً. ولا يصل مال الرواتب إلى الدفتر إلا إذا/عندما يُوصل صرف كشف الرواتب بـ `postSalaryPayment`.

## المخطط

`prisma/models/finance-payroll.prisma`:

- **`SalaryStructure`** — `teacherId`، `effectiveFrom/To`، `baseSalary`، `currency`، `payFrequency`، `isActive`، `notes`.
- **`SalaryAllowance`** — `name`، `amount`، `isTaxable`، `isRecurring`، `description`.
- **`SalaryDeduction`** — `name`، `amount`، `type`، `isRecurring`، `description`.

لا يوجد حقل `lang`. تعالج صفحة قائمة الهياكل ذلك وقت القراءة عبر `getText`، لكن أسماء البدلات/الخصومات الأصلية تُخزَّن غير موسومة.
