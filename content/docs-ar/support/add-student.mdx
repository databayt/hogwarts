## الخطوات

1. افتح **الطلاب** من القائمة الجانبية، ثم اضغط الزر الدائري **+** (إنشاء).
2. **المستندات**: ارفع صورة الطالب وملفاته، مثل الهوية أو الشهادة، وستُملأ بعض الحقول منها تلقائيًا.
3. **البيانات الشخصية**: اسم الطالب، وبيانات ولي الأمر في تبويبَي **الأب** و**الأم**.
4. **العنوان**: مكان سكن الطالب.
5. **الأكاديمي**: الصف والمسار والشعبة، ثم اضغط **إنشاء**.
6. تظهر **بيانات دخول** الطالب، أي اسم المستخدم وكلمة المرور، فانسخها أو أرسلها عبر واتساب أو رسالة نصية أو البريد.

المطلوب فقط اسم الطالب وولي أمر واحد، والباقي يمكن إكماله لاحقًا.

## معلومات مفيدة

- يحفظ المعالج ولي الأمر كجهة اتصال. ولإعطائه دخولًا خاصًا به، استخدم **إنشاء بيانات الدخول**، أو [أدخل أولياء الأمور جماعيًا](/docs/support/bulk-student).
- لإضافة فصل كامل، [الإدخال الجماعي](/docs/support/bulk-student) أسرع.
