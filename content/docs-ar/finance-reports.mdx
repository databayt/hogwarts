description: القوائم المالية — الميزانية العمومية، والأرباح والخسائر، وميزان المراجعة — تُولَّد من دفتر الأستاذ العام. المولّدات ونطاقات التاريخ تعمل، لكن التصدير بلا تنسيق، ولا إرسال بالبريد، وتحويل العملات المتعددة معطّل، ولا يحوي الدفتر اليوم سوى بيانات مدفوعات الرسوم.
---

تولّد التقارير القوائم المالية القياسية من [الدفتر](/docs/finance-accounts). ويتضاعف هنا تحفّظ: بما أن مدفوعات الرسوم وحدها تُرحَّل إلى الدفتر (5 من 6 دوال ترحيل غير موصولة)، فإن القوائم تُقلّل من كل شيء عدا إيراد الرسوم إلى أن يكتمل الترحيل.

## التدفق

```
Pick a report + date range  →  generate from journal entries + account balances
  →  view  →  export (wired to the table, but unstyled / unbranded)
```

## الحالة

| الميزة                         | الحالة                                      |
| ------------------------------ | ------------------------------------------- |
| الميزانية العمومية             | Production                                  |
| الأرباح والخسائر (قائمة الدخل) | Production                                  |
| ميزان المراجعة                 | Production                                  |
| التعمّق في دفتر الأستاذ        | Production                                  |
| نطاق تاريخ مخصص                | Production                                  |
| التصدير (PDF / XLSX / CSV)     | موصول بـ DataTable لكن بلا تنسيق / بلا هوية |
| إرسال التقرير بالبريد          | مخطط                                        |
| تصدير تقارير مجدول (cron)      | مخطط                                        |
| واجهة منشئ تقارير مخصص         | مخطط                                        |
| تحويل العملات المتعددة         | معطّل للمدارس متعددة العملات                |
| قائمة التدفق النقدي (كمسار)    | مخطط (المولّد مُشار إليه، بلا مسار)         |

## إجراءات الخادم

| الإجراء                   | الغرض                                       |
| ------------------------- | ------------------------------------------- |
| `generateBalanceSheet`    | الأصول = الخصوم + حقوق الملكية، بتاريخ محدد |
| `generateIncomeStatement` | الإيرادات − المصروفات خلال فترة             |
| `generateTrialBalance`    | كل الحسابات بإجماليات المدين/الدائن         |
| `getAvailableReports`     | عرض أنواع التقارير + التقارير المحفوظة      |

## دفتر الأستاذ / المحاسبة

**تستهلك** التقارير الدفتر (قيود اليومية + أرصدة الحسابات). ولا ترحّل هي شيئاً. ودقتها محدودة بما يُرحَّل إلى الدفتر — اليوم مدفوعات الرسوم وقيود اليومية اليدوية فقط.

## المخطط

`prisma/models/finance-reports.prisma`: `FinancialReport` — مقيّد بـ `schoolId`، يخزّن بيانات وصفية/لقطات للتقارير المولَّدة.

## العناصر المؤقتة

- `reports/validation.ts:36,47` — رسائل نطاق التاريخ مكتوبة يدوياً.
- مسار تحويل العملات المتعددة معطّل معروف (انظر الحالة).

## الاختبارات

لا يوجد. من الثوابت الناقصة اللافتة: الميزانية العمومية (الأصول = الخصوم + حقوق الملكية)، وميزان المراجعة (إجمالي المدين = إجمالي الدائن)، وتجميع الأرباح والخسائر على الفترة.
