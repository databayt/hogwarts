الصلاحيات هي لوحة التحكم بالوصول المالي. تدير النموذج الهجين: افتراضيات الدور مع صفوف `FinancePermission` لكل مستخدم، ويفحصها `checkCurrentUserPermission()` قبل كل تعديل في كل وحدة فرعية مالية.

## التدفق

```
Pick a view (by user | by module)  →  grant / revoke per module × action
  →  bulk grant / revoke across users  →  copy a permission set from user A to user B
```

## الحالة

| الميزة                                                    | الحالة                              |
| --------------------------------------------------------- | ----------------------------------- |
| نموذج `FinancePermission` (دقيق على مستوى الميزة الفرعية) | Production                          |
| تدفقات المنح / السحب / النسخ                              | Production                          |
| المنح / السحب الجماعي                                     | Production                          |
| عزل المستأجرين + حصر الوصول بـ ADMIN                      | Production                          |
| سجل تدقيق لتغييرات الصلاحيات                              | مخطط (لا سجل لمن/متى — فجوة امتثال) |
| قوالب صلاحيات بحسب الدور                                  | مخطط                                |
| منح محدودة المدة / منتهية الصلاحية                        | مخطط                                |

## المسارات

لا مسار مخصص — يُوصَل إلى الواجهة عبر إعدادات المالية / لوحة المسؤول، لا عبر صفحة `/finance/permissions` مستقلة.

## إجراءات الخادم

كلها محصورة بـ ADMIN ومقيّدة بالمستأجر.

| الإجراء                                          | الغرض                               |
| ------------------------------------------------ | ----------------------------------- |
| `grantPermission` / `revokePermission`           | منح / سحب فردي                      |
| `bulkGrantPermissions` / `bulkRevokePermissions` | التطبيق على مستخدمين كثر دفعة واحدة |
| `copyPermissions`                                | نسخ مجموعة صلاحيات مستخدم إلى آخر   |
| `getPermissionsByModule`                         | الصلاحيات في عرض "بحسب الوحدة"      |
| `getAllUsersWithPermissions`                     | الصلاحيات في عرض "بحسب المستخدم"    |

## المفاهيم

فضاء الصلاحيات هو **12 وحدة مالية × 7 إجراءات**. يعرض `finance/lib/permissions.ts` الدالة `checkCurrentUserPermission()` التي تستدعيها إجراءات الخادم في كل وحدة فرعية قبل أي تعديل — وهي نقطة الإنفاذ الوحيدة لصلاحيات المالية (RBAC).

## دفتر الأستاذ / المحاسبة

ليست محرّكاً للمال.

## المخطط

`prisma/models/finance-reports.prisma`: `FinancePermission` — مقيّد بـ `schoolId`، صف واحد لكل منحة (مستخدم، وحدة، إجراء). لا حاجة لحقل `lang` (مفاتيح الوحدة/الإجراء enums لا نص حر).

## العناصر المؤقتة

- لا سجل تدقيق (فجوة امتثال P1).
- لم يُمرَّر `validation` بعد عبر `ValidationHelper`.

## الاختبارات

لا يوجد. أعلى الفجوات قيمة: حالة المنح/السحب، وحالات النسخ الحدّية (الدورات، الإشارة الذاتية)، والتحقق من الإنفاذ داخل إجراءات كل وحدة فرعية.
