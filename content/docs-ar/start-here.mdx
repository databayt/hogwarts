## كيف يقرّبنا من المال

دخولٌ معطّل تكتشفه أثناء مكالمة بيع يكلّفنا مدرسة. وتكتشفه في فحص من دقيقتين فلا يكلّف شيئًا. والعمل لا يُحسب إلا حيث يُسجَّل — GitHub ونظام إدارة العملاء والمجموعة — فلا بد أن يعمل وصولك إلى الثلاثة.

## جهّز جهازك بـ«كن»

سطر واحد في الطرفية. يأخذ نحو 20 دقيقة، ولا يثبّت إلا الناقص، ويمكن تشغيله مرة أخرى في أي وقت.

```bash
curl -fsSL https://kun.databayt.org/install | bash
```

على ويندوز (PowerShell):

```powershell
powershell -ExecutionPolicy Bypass -Command "iwr https://kun.databayt.org/install.ps1 | iex"
```

تحصل على Claude Code (اكتب `c` لتشغيله)، وكل مستودعات داتابيت منسوخة، والإعداد نفسه الذي عند بقية الفريق. الدليل الكامل: [تجهيز «كن»](https://kun.databayt.org/en/docs/onboarding).

## الفحص

| الفحص                         | كيف                                                                                       | ينجح إذا                      |
| ----------------------------- | ----------------------------------------------------------------------------------------- | ----------------------------- |
| أنت عضو في منظمة databayt     | `gh api user/memberships/orgs/databayt --jq .state`، أو ابحث عن اسمك في [github.com/orgs/databayt/people](https://github.com/orgs/databayt/people) | `active` |
| GitHub يعرف هذا الجهاز        | `gh auth status` ثم `ssh -T git@github.com`                                               | "Logged in" و"successfully authenticated" |
| «كن» سليم                     | `bash ~/.claude/scripts/health.sh`                                                        | `✅ healthy`                  |
| بريدك يعمل                    | ادخل اسمك@databayt.org                                                                    | يفتح صندوق الوارد             |
| نظام إدارة العملاء يفتح       | [hogwarts.databayt.org](https://hogwarts.databayt.org) بالبريد نفسه                        | تظهر صفقاتك                   |
| العرض التجريبي يعمل           | [demo.balqalam.com](https://demo.balqalam.com) على هاتفك ← «جرّب المنصة»                  | تفتح لوحة مدرسة               |
| أنت في المجموعة               | واتساب «المدرسة 2.0»                                                                      | ترى خطة هذا الأسبوع           |

صف أحمر في «كن»؟ `bash ~/kun/.claude/scripts/onboarding-mac.sh --doctor` يطبع إصلاح كل صف، ولا يغيّر شيئًا.

## إذا حدث هذا

- **فحص أحمر ولم يُصلحه تلميحه** ← قلها في المجموعة، مع الصف وما رأيته.
- **حصلت على جهاز جديد** ← شغّل سطر «كن»، ثم الفحص.
- **فقدت الوصول إلى المنظمة أو بريدك أو نظام إدارة العملاء** ← أخبر عثمان في اليوم نفسه.
- **رابط هنا لا يعمل** ← قل أيّها في المجموعة.

## ما عليك

شغّل الفحص الآن، ومرة أخرى على أي جهاز جديد.
