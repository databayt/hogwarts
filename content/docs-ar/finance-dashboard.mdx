تجمّع لوحة المالية الكتلة في نظرة عامة بحسب الدور: يرى المسؤولون والمحاسبون المؤشرات والرسوم كاملة؛ ويرى المعلمون والطلاب وأولياء الأمور شرائح محدودة (راتبه، حالة الرسوم). وهي صفحة الهبوط على `/finance/dashboard`.

## التدفق

```
Load (role-scoped)  →  KPI cards (real totals)  +  trend charts (mock)
  +  smart alerts  +  quick actions  +  recent transactions
```

## الحالة

| الميزة                                 | الحالة                                         |
| -------------------------------------- | ---------------------------------------------- |
| بطاقات مؤشرات بحسب الدور               | Production (تجميعات حقيقية من قاعدة البيانات)  |
| رسوم الإيراد / المصروف / التدفق النقدي | Production (الإجماليات حقيقية)                 |
| تغذية أحدث المعاملات                   | Production                                     |
| ملخص الحسابات البنكية                  | Production                                     |
| نظرة عامة على الميزانية                | Production                                     |
| تنسيق العملة واللغة                    | Production (`School.currency`، لغة `date-fns`) |
| خطوط الاتجاه المصغّرة                  | **مؤقتة — بيانات وهمية من `Math.random()`**    |
| تحديث فوري (WebSocket)                 | مخطط (حالياً SSR للصفحة كاملة)                 |
| تحسين التخطيط للجوال                   | مخطط                                           |

## إجراءات الخادم

| الإجراء                  | الغرض                                                                  |
| ------------------------ | ---------------------------------------------------------------------- |
| `getDashboardStats`      | إجماليات المؤشرات + سلاسل الاتجاه (الإجماليات حقيقية، الاتجاهات وهمية) |
| `getFinancialAlerts`     | تنبيهات ذكية (تأخر، رصيد منخفض، وغيرها)                                |
| `getQuickActionsForRole` | أزرار إجراءات مناسبة للدور                                             |
| `getRecentTransactions`  | تغذية أحدث المعاملات                                                   |

## دفتر الأستاذ / المحاسبة

ليست محرّكاً للمال — تقرأ اللوحة وتجمّع عبر نماذج الفواتير والرسوم والمصروفات والرواتب والبنوك والميزانية والمحفظة للعرض فقط.

## المخطط

لا نموذج خاصاً بها؛ تؤلّف قراءات عبر نماذج المالية الأخرى.

## العناصر المؤقتة

- `dashboard/actions.ts:278-288` — تختلق `generateTrend()` خطوط الإيراد/المصروف/الربح/التحصيل المصغّرة بـ `Math.random()`. يقول التعليق "mock data for now - should calculate from historical data". **إجماليات** المؤشرات حقيقية؛ وخطوط الاتجاه وحدها مزيفة.
