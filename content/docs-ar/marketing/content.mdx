| العمود                      | النسبة | الهدف                              | أمثلة                                               |
| --------------------------- | ------ | ---------------------------------- | --------------------------------------------------- |
| علوم التعلم وذكاء المدرسة   | 30%    | بناء سلطة معرفية وجذب جمهور نوعي   | الاسترجاع النشط، الذاكرة، التغذية الراجعة، التنظيم الذاتي |
| إدارة المدرسة ومشكلاتها     | 30%    | جعل صاحب القرار يتعرف على المشكلة  | الغياب، فوضى الرسوم، القبول، الاعتماد على موظف واحد |

| الثقة والعرض               | 15%    | إزالة المخاوف والتحويل             | السعر، البيانات، الـPilot، قصة الملك فهد دون نتائج مختلقة |

| السلسلة              | الفكرة                                                                         |
| -------------------- | ------------------------------------------------------------------------------ |
| مدرسة تعمل بذكاء     | فكرة تعليمية أو بحثية موثوقة تتحول إلى سؤال على مستوى المدرسة                 |
| من داخل مكتب المدير  | موقف يومي: ولي أمر يتصل، إيصال مفقود، جدول متعارض، ملف قبول ناقص              |

| اسأل بالقلم          | كل منشور يجيب اعتراضا واحدا من [FAQ](/en/docs/competitors/faq) بلغة عامة ودون كشف الملاحظات الداخلية |
| قرار الأسبوع         | Checklist أو سؤال يطلب من مدير المدرسة مراجعة وضعه الحالي                     |

## معادلة القطعة المعرفية

1. **Hook** يفتح فجوة معرفية.
2. المشكلة أو الاعتقاد الشائع.
3. ما يقوله الدليل فعلا.
4. ما لا يثبته الدليل.
5. المعنى بالنسبة للمدرسة.
6. خطوة عملية.
7. **Product bridge** طبيعي إن وجد.
8. **CTA** واحد.

## الـProduct bridge

الربط لا يعني حشر اسم بالقلم في نهاية كل منشور.

| الفكرة                     | الجسر الصادق إلى المنتج                       |
| -------------------------- | --------------------------------------------- |
| الاسترجاع النشط            | تصميم الاختبارات ومتابعة النتائج              |
| الغياب                     | تسجيل الحضور والمتابعة مع الأسرة              |
| التغذية الراجعة            | وصول النتائج والرسائل في وقت مناسب            |
| التباعد في التعلم          | الجدول والدروس وتتبع التقدم                   |
| خصوصية الطالب              | الأدوار، العزل، سجل التدقيق والتصدير          |
| العبء المعرفي على الموظف   | تجميع العمليات بدل التنقل بين الملفات         |

إذا لم يوجد bridge صادق، ينشر المحتوى لبناء الثقة **دون ربط مصطنع**.

## النبرة

- عربية واضحة، ذكية، مباشرة. لا نكتب كمنشور شركة تقليدي.
- نستخدم مشهدا أو سؤالا قبل المصطلح، ونشرح المصطلح عند استخدامه.
- لا نستخدم مبالغات مثل «ثورة» و«يغير كل شيء» و«الأول بلا منافس».
- عند مخاطبة السودان يمكن استخدام نبرة سودانية مثقفة؛ المواد الإقليمية تستخدم فصحى بسيطة.

## سياسة البحث والتحرير

### ترتيب المصادر

1. البحث الأصلي أو الوثيقة الرسمية.
2. المراجعات المنهجية والجهات المستقلة التي تقيم الأدلة.
3. الجامعات والهيئات التعليمية الرسمية.
4. الصحافة العلمية الرصينة لشرح الخبر، مع الرجوع للمصدر الأصلي.
5. لا نعتمد على حسابات social media كمصدر للادعاء.

### تصنيف الدليل

| العلامة       | المعنى                                              |
| ------------- | --------------------------------------------------- |
| قوي           | مدعوم بمراجعات متعددة أو نتائج مستقرة               |
| واعد          | نتائج جيدة لكن السياق أو الحجم محدود                |
| أولي          | دراسة واحدة أو preprint؛ يقدم كاحتمال لا كحقيقة     |
| مضلل / خرافة  | لا يملك دعما كافيا أو يشوه النتيجة                  |

### الحماية من neuroscience marketing

لا ننشر:

- «هذه الطريقة تعيد برمجة دماغ الطالب».
- ادعاءات الدوبامين المبسطة.
- أنماط التعلم كحقائق بيولوجية ثابتة.
- صورة دماغ كدليل في حد ذاتها.
- تحويل correlation إلى causation.
- نتيجة بحث على بالغين كحقيقة مؤكدة للأطفال.

### فصل الطبقات

اكتب بوضوح، وعدم خلط هذه الطبقات جزء من هوية العلامة:

- **الدراسة وجدت:** النتيجة التي يدعمها المصدر.
- **هذا قد يعني للمدرسة:** تفسيرنا المهني.
- **في بالقلم:** ما يفعله المنتج فعليا.

### مراجعة المنتج قبل النشر

- [ ] الاسم بالقلم وليس الاسم القديم.
- [ ] الميزة موجودة في [MVP](/docs/mvp).
- [ ] الرقم موجود في [سجل الادعاءات](/docs/marketing/claims).
- [ ] الدولة مناسبة للادعاء.
- [ ] لا يوجد وعد Offline أو App Store أو analytics متقدمة.
- [ ] لا توجد نتيجة من Case Study غير موثقة.
- [ ] الـCTA ممكن تنفيذه الآن.
