## ما هو بالقلم؟

نظام عربي متكامل لإدارة المدرسة من القبول وحتى التقارير والرسوم والتواصل مع الأسرة.

- **العربية هي اللغة الافتراضية**، وليست طبقة ترجمة أضيفت لاحقا.
- **بيانات كل مدرسة منفصلة** عن بيانات المدارس الأخرى.

## ما الذي يحصل عليه العميل؟

استخدم عمود «الوصف التسويقي الآمن» كما هو أو قريبا منه — لا تضف وعودا عليه.

| المجال               | الوصف التسويقي الآمن                                                                      |
| -------------------- | ----------------------------------------------------------------------------------------- |
| القبول               | يقدم ولي الأمر من رابط المدرسة ويتابع حالة الطلب دون إنشاء حساب، ثم يتحول المقبول إلى طالب مسجل |
| الحضور               | تسجيل الحضور ومتابعة الغياب والأعذار                                                      |
| الامتحانات والدرجات  | الجداول، أوراق الامتحان العربية، الرصد، الشهادات والتقارير                                |
| الرسوم والمالية      | خطط رسوم، أقساط، فواتير، إيصالات، خصومات ومنح                                             |
| الجدول               | بناء الجدول مع منع تعارض المعلم أو الغرفة                                                 |
| بوابة الأسرة         | حضور ودرجات وتقارير ورسوم ورسائل لكل طفل                                                  |
| الرسائل              | إعلانات، محادثات وقنوات تسليم تشمل واتساب بحسب الإعداد                                    |
| التعلم الإلكتروني    | دروس وفيديو وتتبع تقدم وشهادات إكمال                                                      |
| النقل                | خطوط ومحطات ومتابعة صعود ونزول الطلاب                                                     |
| المكتبة              | فهرسة واستعارة                                                                            |
| الإعداد              | ترسل المدرسة ملف Excel الحالي ويقوم الفريق بالتجهيز والاستيراد                            |
| الموظفون والرواتب    | موجود بصورة جزئية، ولا ينبغي أن يكون مقدمة العرض                                          |

## الإثبات المتاح حاليا

- Demo عام يمكن تجربته — [العرض التجريبي](/docs/demo).
- واجهة عربية حقيقية.
- مدرسة واحدة يمكن تسميتها علنا: **مدارس الملك فهد في الخرطوم**.
- لقطات شاشة عديدة تحتاج القص والتوحيد البصري.
- تفاصيل تقنية كثيرة، لكن لا ينبغي أن تكون مقدمة الخطاب التسويقي.

## الرسالة الأساسية

> مدرستك كلها في مكان واحد: القبول والحضور والرسوم والنتائج والتواصل، بنظام عربي يبدأ من البيانات التي لديك بالفعل.

الأسعار، عرض الـPilot والـCTA المسموح في [العرض ومسار التحويل](/docs/marketing/offer). التعارضات المفتوحة في [سجل الادعاءات](/docs/marketing/claims).
